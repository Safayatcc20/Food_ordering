# Food Ordering System

## Description
The **Food Ordering System** is a web-based application built using JavaScript, HTML, and CSS. It enables users to browse a menu, add items to their cart, and simulate the food ordering process. This project focuses solely on the **frontend development**, making it a great practice project for learning and showcasing web development skills.

## Features
- **User-Friendly Interface**: A visually appealing layout created with HTML and CSS.
- **Dynamic Menu Display**: JavaScript is used to display menu items dynamically.
- **Add to Cart**: Users can select items, specify quantities, and view their cart in real time.
- **Order Summary**: A detailed summary of selected items, including total cost.
- **Responsive Design**: Optimized for mobile and desktop screens.

## Technologies Used
- **HTML**: For structuring the web pages.
- **CSS**: For styling and layout design.
- **JavaScript**: For interactivity and dynamic functionality.

## Usage
1. Open the application in a web browser.
2. Browse the menu items and select your desired food.
3. Add items to the cart and view the order summary.
